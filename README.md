# EGP IfcOpenShell Utils
Утилиты для работы с IFC-файлами через библиотеку [IfcOpenShell](https://ifcopenshell.org/).

## Содержание  
* Безопасность
* Общее описание
* Инструкция для разработчиков
* Инструкция для пользователей
* Полезные ссылки и примечания

## Безопасность
Файлы конфигурации (TSV-таблица маппинга) содержат исполняемый Python-код в столбцах Rule и Parameter Value. Инструмент выполняет этот код. Никогда не запускайте инструмент с конфигурациями, полученными из непроверенных источников. Не встраивайте утилиту в веб-сервисы без изоляции и экранирования ввода.

## Общее описание
Репозиторий содержит инструменты для автоматизации работы с файлами IFC (Industry Foundation Classes).  
  
**Особенности**  
* Работа через библиотеку IfcOpenShell.
* Конфигурация через текстовые файлы и TSV-таблицы.
* Поддержка пользовательских правил на Python для отбора элементов и вычисления значений.  
  
**Структура репозитория**
* ```src``` — исходный код утилит.
* ```release``` — сборка (готовые к использованию утилиты).
* ```samples``` — примеры конфигураций, исходные и обработанные IFC модели.

**Общие правила конфигурации**
* ``` ## ``` в начале строки — комментарий.
* Пустые строки игнорируются.
* Пути только абсолютные.
* Таблицы ```.tsv``` обязаны быть с заголовками.
* Нельзя переименовывать/удалять папку ```Configs``` и ```.txt``` файлы.

## Инструкция для разработчиков

Перед началом разработки ознакомьтесь с разделом **Безопасность**.

**Требования**
* Python 3.13 или выше.
* IFC Open Shell 0.8.5 или выше.
* Visual Studio Code (рекомендуется) или другая IDE.
* PyInstaller для сборки исполняемых файлов.

**Подготовка среды**
1. Установите Python с [официального сайта](https://www.python.org/). При установке отметьте опцию Add Python to PATH.
2. Установите [Visual Studio Code](https://code.visualstudio.com/).
3. В VS Code установите расширения для Python (Python, Pylance, Python Debugger, Python Environment).
4. В VS Code Выберите установленный интерпретатор Python.
5. В терминале VS Code выполните:
```bash
pip install ifcopenshell
```
6. (Опционально) Настройте тему оформления.   

**Сборка исполняемого файла**
1. Создайте папку для сборки.
2. Выполните:  
```bash
pyinstaller --onefile --collect-data ifcopenshell main.py
```
3. Скопируйте содержимое ```dist``` в папку для сборки.
4. Скопируйте ```Configs``` в папку для сборки.  

## Инструкция для пользователей
### ParameterByMappingWriter  
Утилита предназначена для создания и заполнения параметров IFC-элементов по заданному маппингу.  
Позволяет редактировать базовые атрибуты (например, Name) и свойства в наборах (Pset).  

**Как это работает**  
Для каждого целевого параметра в таблице маппинга указываются:  
| Поле | Описание |
| :--- | :--- |
| Aim Parameter Name | Имя параметра/атрибута, который будет создан или изменён |
| Parameter Type | IFC-тип значения (например, ```IfcText``` или ```IfcReal```) |
| Parameter Set | Набор свойств (Pset) или ```IfcBaseParameters``` для базового атрибута |
| Aim IFC Class | Класс IFC-элементов для обработки |
| Rule | Python-выражение, возвращающее ```True```/```False``` для отбора элементов |
| Parameter Value | 	Python-выражение, вычисляющее значение параметра |  

В Python-выражениях доступны переменные:
* ```elem``` — текущий элемент IFC.
* ```info``` — результат ```elem.get_info()```.
* ```psets``` — наборы свойств элемента.  
  
**Особенности**
* Если ```Parameter Set = IfcBaseParameters```, значение записывается напрямую в атрибут элемента (Name, Description и т.д.).
* В остальных случаях: при отсутствии Pset он будет создан, свойство добавится или обновится.
* Ошибки при вычислении правил или записи (например, неверный тип) приводят к пропуску элемента с сообщением в консоль, обработка остальных продолжается.
* Тип можно указывать как коротким алиасом (```text```, ```real```, ```boolean```, ```integer```, ```logical```), так и полным именем IFC-типа.
* Если вы работаете с гугл таблицей, то используйте обратный апостроф в начале строки ``` ` ```, чтобы содержимое не превращалось в формулу.
* Внутри Python-выражений необходимо использовать одинарные кавычки ``` ' ```.

**Настройка и запуск**
1. Скопируйте папку с исполняемым файлом в удобное место (из ```release``` в данном репозитории).
2. Подготовьте таблицу маппинга в формате TSV (ссылка на шаблон приведена ниже).
3. Настройте конфигурационные файлы в папке ```Configs```:  
  3.1 ```ModelPathsConfig.txt``` — абсолютные пути к .ifc файлам (по одному на строку).  
  3.2 ```OutputPathConfig.txt``` — путь к папке для сохранения обработанных файлов (директория должна существовать).  
  3.3 ```ParameterMappingConfig.txt``` — путь к TSV-файлу с маппингом.
4. Запустите main.exe (ошибки будут выведены в консоль).
5. Дождитесь завершения программы (консоль сама закроется).
6. Проверьте итоговые IFC.
7. При необходимости добавьте запуск в планировщик.
